# ai-archaeology-restoration# AI for Archaeological Restoration

## Description
This project explores the use of artificial intelligence for digital restoration of damaged archaeological artifacts.  
The system analyzes fragments, reconstructs missing parts, and enables further 3D visualization.

## Author
Ayazhan Satova. Team Subsquad Oral

## Date of creation

## Project status
Research / Prototype

## Purpose
To make archaeological restoration faster, more accessible, and affordable for students and researchers with limited resources.

AI-based project for digital restoration of archaeological artifacts
